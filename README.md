# Subtitle Focus – Easy-Read Captions: support

**Subtitle Focus** is a free Chrome extension by [Zillionn Ltd](https://zillionn.com)
that makes video subtitles easier to follow by bolding the start of each word.

This repository is where you can **report a problem** or **ask for a site to be
supported**. (The extension's source code is kept separately.)

## Report a problem

1. Click the **Issues** tab above, then **New issue**.
2. Pick the form that fits:
   - **Subtitles not detected on a site**: the extension doesn't work on a website.
   - **Something else isn't working**: any other bug.
3. Fill it in and click **Submit new issue**.

**Quickest way:** open the Subtitle Focus popup on the page where it isn't
working and click **Report this site**. The form opens with the site's name
and the technical details already filled in.

You need a free GitHub account to submit. Please don't include personal
information: reports here are public.

No GitHub account? Email **dev@zillionn.com** instead.

## Before you report

- Make sure subtitles (**CC**) are switched on in the video player.
- Some sites draw subtitles into the video picture itself (burned-in
  subtitles, or some protected streaming services). There's no text for the
  extension to restyle there, so it can't help on those sites.
- Chinese, Japanese, Korean, Arabic, Hebrew, Thai and Indic scripts are left
  unchanged on purpose.
